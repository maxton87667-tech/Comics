Comic Panel Renamer

A Python utility to seamlessly merge and sequence screen-recorded comic chapters.

About The Tool

When recording long digital drawing and storyboarding sessions, screen recorders often hit their limit and split the video. Extracting images from these split videos results in overlapping frame numbers (e.g., both parts starting with IMG0.jpg).

This tool safely merges those split folders into one continuous sequence without overwriting your hard work.

Features

  • Zero Data Loss: Creates copies instead of renaming original files.
  • Smart Sorting: Maintains the correct order of extracted frames.
  • Android/Termux Ready: Fully compatible with mobile environments.

How to Use in Termux

  • Step 1: Create a main folder. Inside it, create part1 and part2 folders. Place your extracted images inside them respectively.
  • Step 2: Place the rename.py script outside the part folders, but inside the main folder.
  • Step 3: Open Termux and install Python if you haven't:
    pkg install python
  • Step 4: Navigate to your folder and run the script:
    python rename.py
